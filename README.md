# 英语四级核心词库 · 3000 词

在线背单词应用：<https://yuann112233.github.io/cet4-wordbank/>

## 内容

- `index.html` —— 单文件网页应用，离线可用（词库数据已内嵌）
- `cet4-3000-words.csv` —— 词表 CSV（UTF-8 BOM）
- `cet4-3000-words.xlsx` —— 词表 Excel

## 词库说明

3000 词，每条含：单词 / 音标 / 词性 / 中文释义 / 标签。

标签分三档：

- **高频** 1396 词 —— 四级大纲与人工审核清单双重收录，优先背
- **核心** 1190 词 —— 四级大纲收录
- **一般** 414 词 —— 大纲表外的补充词（四级增量词）

## 功能

词库浏览与搜索 · 字母/标签/状态筛选 · 闪卡翻面评分 · 英中/中英/拼写测验 ·
错词本 · 学习统计 · 进度本地保存（localStorage，不上传）
